从 PolicyWatcher 到 PALO

  1. 收到监测信号

    PolicyWatcher 发布了 Google Gemini 应用工作和学校账号的变更证据包。试点以只读方式获取证据，并重新计算了证据包摘要。

    变更编号 429e2afa-3202-4708-97b6-1797cf3fca26

  2. 冻结规则

    字典将变更编号、来源网址和监测权限绑定到一条规则。证据不足或审批人数未达要求均会阻止发布。试点角色按脚本激活了完整版本。

    发布清单 4de3a9de98da7885934b3d46c3507a4729234caf909782a3de2174185fc9e22c

  3. 观测准入结果

    独立消费端接纳了匹配的信号。替换变更编号后，信号仍符合原生格式，但语义规则将其暂缓。自称具有审批权限的监测信号也被暂缓。

    应用 review-intake

  4. 等待人工复核

    本地 Assessment Path 重新打开 Measure（衡量）和 Prove（验证）。重新加载后，案例和证据仍被保留。原生回执对应这次重开的案例；生产部署和政策适用性仍待决定。

    案例状态 pending-human-review
独立实验室

  1. 本地工作区

    模拟校准实验室从空注册表开始。操作系统禁止联网，运行环境仅使用 Python 和 SQLite。

    工作区 north-quay-calibration

  2. 证书规则

    实验室在自己的分类体系中将最终证书归入证书类。其规则要求先记录测量不确定度预算，再发出最终证书。

    控制项 certificate-check

  3. 观测工作台

    完整证书获准，缺少预算的证书被暂缓，草稿不在适用范围内。仅有回执时激活尚未证实，之后通过观测工作台完成了验证。

    应用 bench

  4. 确认已停用

    收到撤回回执后，实际效果仍待验证。独立观测记录了工作台已停用，才确认该模拟消费端的撤回已生效。

    观测状态 withdrawal_verified
