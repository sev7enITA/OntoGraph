# Follow a disputed WBS mapping through withdrawal

The bare code 0017 denotes a posting object in a Finance ledger and can denote a work package in PMO. Two assessors supplied separate sources, grades and rationales for the same relationship. The registry refused publication of an unresolved candidate despite two scripted votes. The reviewer accepted the Finance mapping only in its qualified departmental context. Both original claims remain in the release. [Review the original and resolved models](https://openontograph.org/wbs/)

1. Download the unresolved model in the walkthrough. Sign into the web Studio and choose **Relationship evidence**. Open the model and inspect the declared mapping. [Authenticated Studio](https://openontograph.org/OntoGraph/decisions/?lang=en)
2. Inspect both sources and compare the grades. Record a resolution naming the reviewer, selected claim and reason. Save and reload. Change a claim and inspect the resolution status again. The exact assertions and sources are bound to the reviewer’s decision. The named reviewer must cast an authenticated approval on the candidate before registry publication. [Release protocol](https://github.com/sev7enITA/OntoGraph/blob/main/docs/PROTOCOL.md#several-judgments-about-one-relationship)
3. Follow Beancount and LibreOffice Calc across the checkpoints. A matching receipt coexisted with stale spreadsheet results. After withdrawal, the ledger admitted €0 while the workbook still included €800. The workbook later became inaccessible, leaving its state unproven. Real reads of €0 in both applications established withdrawal on the declared cases. An explicitly approved release restored the baseline. [Independent application readbacks](https://openontograph.org/wbs/)
4. Download the evidence archive and verify it offline. It contains 15 application readings and a 70-event registry chain, including the source files used by the two native engines. These are local independent applications running synthetic data under scripted roles. [Reproduction instructions](https://github.com/sev7enITA/OntoGraph/tree/main/examples/wbs_pilot)
