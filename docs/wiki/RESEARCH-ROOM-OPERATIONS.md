# Maintain a private research room

The reading room authenticates on the server. Deploy the generic contents of `site/research-room/` under HTTPS. The sign-in page uses a dedicated session cookie, an inactivity limit of 30 minutes, an eight-hour absolute limit, CSRF checks and a per-client attempt limit. Each authorized request rechecks the configured password hash. Use PHP with PDO SQLite and sessions, and bypass CDN caching on this path.

Create a directory named `private-research` beside the site's document root. Restrict this directory to the service account. Install a bcrypt password hash generated by PHP as `password.hash` and the compiled collection as `library.json`. Keep plaintext credentials in the operator's password store. Replacing the hash invalidates existing room sessions.

Maintain bilingual Markdown sources and their manifest outside the checkout. Each manifest entry has an opaque ID, display date, English and Chinese titles and summaries, and an English and Chinese category (`category` and `zhCategory`). Use `ID.en.md` and `ID.zh.md` for the articles. Compile with Python 3.10+ and Pandoc using `python3 tools/build_research_library.py PRIVATE_SOURCE_DIR PRIVATE_OUTPUT_DIR/library.json`. Upload to a temporary filename in the private directory and rename it atomically after validation.

After deployment, use a fresh browser context to check the login page, rejected password, protected content after sign-in, expiration or logout, and the absence of private data through direct public URLs. Confirm cache and robots headers and verify both languages. Previously published public references retain their original visibility.
